# Mano Salon – Website (Deutsch / Österreich)

## WICHTIG: Alle Dateien hochladen
Die ZIP-Datei entpacken. **Den INHALT des Ordners** in das GitHub-Repository hochladen, nicht nur `index.html` und nicht den übergeordneten Ordner.

Im Hauptverzeichnis von GitHub müssen `index.html`, `style.css`, `common.js`, `calendar.js`, `booking.html`, `galerie.html`, `preise.html`, `kontakt.html` und der Ordner `images` sichtbar sein. Ohne `style.css` erscheint die Seite weiß und ungestaltet. Ohne `images` fehlen die Fotos.

GitHub → Add file → Upload files → Dateien samt images-Ordner hineinziehen → Commit changes. Dann Settings → Pages → Deploy from branch → main → /(root) → Save.

Die Menüpunkte öffnen eigene Unterseiten derselben Website.

Hinweis: Der Kalender zeigt Daten, aber keine Echtzeit-Verfügbarkeit. Die eigentliche Buchung erfolgt extern bei Treatwell. Preise und Öffnungszeiten vor Veröffentlichung überprüfen. Impressum/Datenschutzerklärung nach österreichischen Vorgaben ergänzen.
